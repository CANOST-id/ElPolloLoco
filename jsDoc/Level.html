Class: Level

Level(enemies, clouds, backgroundObjects, coins, bottles)

Level class representing a game level with its elements. Contains all game objects like enemies, clouds, background elements, and collectibles.

Constructor

new Level(enemies, clouds, backgroundObjects, coins, bottles)

Creates a level with specified game elements.

Parameters:
Name Type Description
enemies Array.<MovableObject>

Array of enemy objects in the level
clouds Array.<Cloud>

Array of cloud objects in the level
backgroundObjects Array.<BackgroundObject>

Array of background object elements in the level
coins Array.<Coin>

Array of coin objects in the level (optional)
bottles Array.<Bottle>

Array of bottle objects in the level (optional)
